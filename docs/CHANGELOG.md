# Changelog

All notable changes to Northbridge will be documented in this file.

This project follows the principles of semantic versioning.

Version format:

```text
MAJOR.MINOR.PATCH
```

* **MAJOR** — Breaking changes
* **MINOR** — New features and improvements
* **PATCH** — Bug fixes and small enhancements

---

# [1.0.0] - 2026-07-26

## Initial Release

Northbridge v1.0.0 marks the first public release of the template.

### Added

* Modern SaaS landing page template
* Next.js 16 App Router architecture
* React 19 support
* TypeScript integration
* Tailwind CSS styling
* Component-based project structure
* Responsive layouts
* SEO-ready metadata
* Framer Motion animations
* Lucide React icons
* Professional documentation
* Installation guide
* Customization guide
* MIT License
* Commercial release packaging

### Improved

* Repository structure standardized
* Product documentation rewritten
* Commercial-ready README
* Product metadata verified
* Release engineering completed

### Fixed

* Removed default Next.js starter assets
* Removed template documentation
* Removed unnecessary development artifacts
* Cleaned project structure for commercial distribution
