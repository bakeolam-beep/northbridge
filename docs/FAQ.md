# Frequently Asked Questions

This document answers common questions about Northbridge.

---

# Which technologies does Northbridge use?

Northbridge is built with:

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide React

---

# Can I use Northbridge for commercial projects?

Yes.

Your purchase allows you to use Northbridge for personal and commercial projects according to the included license.

Please review the LICENSE file for complete terms.

---

# Can I customize the template?

Absolutely.

Northbridge was designed to be customized.

You can change:

* Colors
* Typography
* Branding
* Navigation
* Sections
* Images
* Metadata
* Content

See the **Customization Guide** for detailed instructions.

---

# Do I need to know Next.js?

Basic knowledge of HTML, CSS, JavaScript, and React will help.

Experience with Next.js is recommended but not required for basic customization.

---

# Which Node.js version should I use?

Use the latest LTS version of Node.js for the best compatibility.

---

# Can I use another package manager?

Yes.

Northbridge works with:

* npm
* pnpm
* yarn
* bun

Use your preferred package manager.

---

# Does the template support mobile devices?

Yes.

Northbridge is fully responsive and optimized for modern desktop, tablet, and mobile browsers.

---

# Does Northbridge include backend functionality?

No.

Northbridge focuses on the frontend experience and can be integrated with your preferred backend or API.

---

# Can I deploy Northbridge anywhere?

Yes.

Northbridge supports deployment to platforms compatible with Next.js, including:

* Vercel
* Netlify
* Railway
* Render
* Self-hosted environments

---

# Where can I get support?

Please refer to the Support Guide included in the documentation.

Thank you for choosing Northbridge.
