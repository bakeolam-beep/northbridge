# Support

Thank you for purchasing Northbridge.

This document explains what support is available for the product.

---

## What's Included

Support includes:

* Installation assistance
* Guidance on template customization
* Help with documented features
* Clarification of configuration options
* Bug reports for the current release

---

## What's Not Included

Support does not include:

* Custom feature development
* Design services
* Third-party integrations
* Custom application development
* General programming tutoring

---

## Reporting Issues

When requesting support, please include:

* Product version
* Operating system
* Node.js version
* Browser (if applicable)
* Error messages
* Steps to reproduce the issue

Providing this information helps us investigate and resolve problems more efficiently.

---

## Product Updates

Northbridge may receive updates that include bug fixes, improvements, and new features.

Please refer to the changelog for version history.

---

## Feedback

Suggestions and feature requests are always welcome.

Customer feedback plays an important role in shaping future BakeBeep products.

Thank you for supporting BakeBeep.
